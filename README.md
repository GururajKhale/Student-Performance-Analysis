# Student Performance Analysis

**Author:** Gururaj Khale
**Program:** IBM SkillsBuild Data Analytics with AI (BharatCares x AICTE)

## Project Description

This project analyzes student performance data to understand which everyday habits are associated with better exam scores.

The analysis focuses on study time, attendance, sleep, support at home, and exam scores.

## Goal

The goal of this project is to explore patterns in student performance data and understand how everyday habits are related to exam scores.

## Technologies Used

* Python
* Jupyter Notebook
* Pandas
* NumPy
* Matplotlib

## Dataset

The project uses the `student_performance.csv` dataset included in this repository.

## Project Files

* `Gururaj_Khale_StudentPerformanceAnalysis.ipynb` - Main Jupyter Notebook containing the analysis.
* `student_performance.csv` - Dataset used for the analysis.
* `requirements.txt` - Python libraries required to run the project.
* `Gururaj_Khale_ProjectReport.docx` - Complete project report.
* `README.md` - Project overview and setup instructions.

## Setup and Run Instructions

1. Install Python.
2. Install the required Python libraries using the following command:

```bash
pip install -r requirements.txt
```

3. Open the project folder in Jupyter Notebook.
4. Open `Gururaj_Khale_StudentPerformanceAnalysis.ipynb`.
5. Run the notebook cells from top to bottom.

## Analysis Focus

The analysis explores the relationship between:

* Study time and exam scores
* Attendance and exam scores
* Sleep and exam scores
* Support at home and exam scores
